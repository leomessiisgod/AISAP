# EXPO DESK 서비스 데모 v1 (2026-11-05)

전시 참가기업의 준비 업무(서류·일정·규정 확인)를 돕는 AX Assistant의 UI 데모입니다.

- 구조: 팀원 데모 EXPO DESK(expo-desk-two.vercel.app)의 기능을 스탠다드 모델로 유지
- 디자인 언어·AI 구동 방식: 피처링(app.featuring.co) 참고
- 근거 데이터: AISAP 정제 데이터셋 (COEX 웹 10문서 52청크 + CAD 도면 9문서 19청크)

## 여는 방법
`index.html`을 더블클릭하면 됩니다. 서버나 설치가 필요 없습니다. 인터넷이 없으면 글꼴만 기본 글꼴(맑은 고딕)로 바뀝니다.
체크·업로드 같은 조작은 각자 브라우저에만 저장되고, 사이드바 아래 '데모 데이터 초기화'로 처음 상태로 돌아갑니다.

## 근거 태그
- 보라색 태그: AISAP 정제 데이터셋 원문으로 바로 열립니다(청크 ID·출처·검증 단계 표시).
- 회색 태그(이용안내서 p.26 등): 원문 PDF를 아직 연결하지 않아 안내만 보여줍니다.

## 아직 연결 안 된 부분
- AI 답변은 실제 LLM이 아닙니다. 준비된 시나리오 약 18개 + 데이터셋 글자 단위 검색(원문 발췌)으로 동작합니다.
- 파일 업로드·양식 다운로드·원문 PDF 열기는 알림으로만 보여줍니다.
- 회사·전시회·주최사·일정·점검 결과는 모두 가상(DEMO)입니다.
- 'Hall A 분할 사용'은 사용자 결정대로 확정하지 않고 웹 공시와 도면을 함께 보여줍니다.
